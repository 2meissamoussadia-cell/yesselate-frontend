## 📖 GUIDE D'UTILISATION

### Navigation Rapide (⌘K)
1. Appuyer sur `Ctrl+K` (ou `Cmd+K` sur Mac)
2. Taper le nom de la section recherchée
3. Utiliser les flèches pour naviguer
4. Appuyer sur `Enter` pour sélectionner

### Breadcrumbs
- Cliquer sur n'importe quel élément pour naviguer
- L'élément actuel est en surbrillance
- Icône "Home" pour retour à l'accueil

### Filtres Contextuels
- Cliquer sur un filtre pour ouvrir le menu
- Sélectionner une ou plusieurs options
- Le compteur indique le nombre de sélections
- Bouton "X" pour effacer un filtre
- "Effacer tout" pour réinitialiser

### Redirections
- Automatiques et transparentes
- Les anciennes URLs sont redirigées vers les nouvelles
- Aucune action manuelle requise
