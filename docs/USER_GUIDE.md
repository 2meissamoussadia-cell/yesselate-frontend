# 📖 Guide utilisateur BMO

BMO (Business Management Outlook) est la plateforme de gestion de chantiers BTP de YESSALATE BTP / NICE RÉNOVATION SAS.

## Accès

- **URL** : selon environnement (ex. https://bmo.yessalate.sn)
- **Identifiants démo** : `demo@yessalate.sn` / `Demo123!`

## Fonctionnalités principales

- **Tableau de bord** : KPIs, widgets, vue d’ensemble pilotage.
- **Alertes** : centre d’alertes, traitement des incidents.
- **Demandes** : création et suivi des demandes (travaux, budget, fournitures).
- **Validation BC** : circuit de validation des bons de commande.
- **Gouvernance** : tableaux de bord et rapports.
- **Chantiers, Planning, Qualité, Documents, Messages** : voir le menu principal.

## Navigation

- **Menu latéral** : accès aux modules (Pilotage, Exécution, Support, etc.).
- **Fil d’Ariane** : contexte actuel (section / sous-section).
- **Recherche** : raccourci Ctrl+K pour accéder aux modules et actions.
- **Menu utilisateur** (trois points) : Fichier, Paramétrage, Réglage, langue, thème.
